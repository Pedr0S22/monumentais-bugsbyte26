# Developers Profiles - LettyQuest

This folder stores team profiles and contacts for the BugsByte 2026 hackathon.

How to add your profile:
- Create a markdown file under `profiles/` named after you (e.g., `yourname.md`).
- Include: role, focus area (backend, frontend, data/LLM, product/design), contact (email/Discord), and availability during the event.
- If you own a feature, note it (e.g., scoring, chatbot, frontend wiring) so coordination is easy.

Use these profiles for quick ownership lookup and outreach during the sprint.
