# Product Documentation - LettyQuest

This directory collects product-facing docs for the hackathon demo.

Suggested contents:
- Product brief: problem, audience (desk workers/students), value prop, core loop (log → score → Letty reacts → energy forecast → tips).
- Feature definitions: energy bar rules, Letty mood thresholds, points/streaks, photo log flow, chat boundaries (no medical diagnoses), local LLM (Ollama/HF) + RAG scope.
- UX handoff: link to Figma, color/mood references, copy snippets for Letty’s notifications.
- Demo script: expected happy path and backup path (manual meal entry) for live judging.
- Safety/guardrails: disclaimers, allergen cautions, when to defer to clinicians.

Keep this concise so devs and presenters can align quickly during the event.
